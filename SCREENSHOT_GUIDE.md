# Screenshot Capture Guide

Step-by-step instructions to create a demo repo, trigger Railo, and capture screenshots for the GitHub Marketplace listing.

---

## Step 1: Create the demo repo on GitHub

1. Go to `github.com/new`
2. Create repo: `IWEBai/railo-demo` (or use your personal account)
3. Make it **public** (screenshots look better with public repo context)
4. Initialize with a README (or not — we'll push everything)

## Step 2: Push the clean base to `main`

```bash
cd railo-demo
git init
git remote add origin https://github.com/IWEBai/railo-demo.git

# Create a minimal safe main branch first
echo "# railo-demo" > README.md
echo "Demo repo for Railo — intentional vulnerabilities for testing." >> README.md
git add README.md
git commit -m "Initial commit"
git push -u origin main
```

## Step 3: Install Railo on the repo

If not already installed:
- Go to `https://github.com/apps/railo-cloud/installations/new`
- Select the `railo-demo` repo

## Step 4: Create a feature branch with vulnerable code

```bash
git checkout -b add-user-features

# Copy all files from docs/demo-repo/ into the repo root:
#   app.py
#   server.js
#   utils/crypto.py
#   api/routes.py
#   templates/profile.html

git add -A
git commit -m "Add user management features"
git push -u origin add-user-features
```

## Step 5: Open a Pull Request

1. Go to the repo on GitHub
2. Click "Compare & pull request" for the `add-user-features` branch
3. Title: `Add user management API and profile pages`
4. Description: Something realistic — "Adds user CRUD, search, profile templates, deployment endpoint, and crypto utilities."
5. Create the PR

## Step 6: Wait for Railo

Railo will:
1. Show a pending check on the PR (`Railo/compliance`)
2. Run the scan (30-60 seconds)
3. Post a PR comment with findings
4. Open one or more Fix PRs

## Step 7: Capture Screenshots

### Screenshot 1: PR Check + Comment (HERO SHOT)

**What to capture:** The original PR showing:
- The Railo status check (failing, with findings count)
- The PR comment listing all findings with CWE tags
- The Fix PR link in the comment

**How:** Full browser window, PR "Conversation" tab visible. Make sure the comment is fully expanded.

**Crop:** Include the PR title, the checks section, and the Railo comment. Exclude browser chrome if possible.

### Screenshot 2: Fix PR Diff (MOST IMPORTANT)

**What to capture:** The Fix PR that Railo opened, showing the "Files changed" tab with:
- The SQL injection fix (f-string → parameterized query)
- The secrets fix (hardcoded string → `os.environ.get()`)

**How:** Click into the Fix PR → "Files changed" tab. Expand the `app.py` diff.

**Crop:** Show the diff clearly — green/red lines. The before/after should be readable at a glance.

### Screenshot 3: Fix PR Description

**What to capture:** The Fix PR "Conversation" tab showing:
- The PR title (auto-generated by Railo)
- The description body with CWE tags
- Verification evidence (if included)
- The clean green "Merge" button

**How:** Stay on the Fix PR, "Conversation" tab. Scroll to show the full description.

### Screenshot 4: Warn Mode Comment (if available)

If you run Railo in `warn` mode on a separate test, capture:
- The PR comment showing "proposed fixes" without any auto-changes
- The diff suggestions inline

### Screenshot 5: Dashboard (optional)

If your dashboard is running:
- Navigate to the Railo dashboard
- Show the scan history for the demo repo
- Show a successful scan with findings count

## Screenshot Specs for Marketplace

- **Minimum resolution:** 1280x800px
- **Format:** PNG
- **Browser:** Use a clean browser window (no bookmarks bar, minimal extensions)
- **Theme:** GitHub's default light theme looks best in Marketplace listings
- **Tip:** Use GitHub's light mode for screenshots even if you prefer dark mode — the Marketplace page is light-themed

---

## After Capturing

1. Save screenshots to `docs/screenshots/` (create folder)
2. Name them: `marketplace-01-pr-check.png`, `marketplace-02-fix-pr-diff.png`, etc.
3. Upload to the Marketplace listing form
4. Delete the demo repo (or keep it for future demos)
